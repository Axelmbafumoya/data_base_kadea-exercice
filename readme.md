# Kadea Chat — Base de données

## Présentation

**Kadea Chat** est une plateforme de messagerie destinée aux apprenants de Kadea.

Ce projet consiste à concevoir et mettre en place la **base de données relationnelle** de l'application. Elle permet de gérer les utilisateurs, les conversations, les participants et les messages.

La base de données a été conçue avec **PostgreSQL** en respectant les principes de modélisation relationnelle et de normalisation.

---

## Technologies

- **PostgreSQL** : système de gestion de base de données
- **pgAdmin** : outil de gestion et d'administration de PostgreSQL
- **Draw.io** : conception du dictionnaire de données, du MCD et du MLD
- **SQL** : création et manipulation de la base de données
- **Git / GitHub** : gestion et hébergement du projet

---

## Modélisation

La base de données est composée de quatre tables principales :

- **utilisateurs** : contient les informations des utilisateurs de Kadea Chat.
- **conversations** : représente les conversations de l'application.
- **participations** : permet de gérer les utilisateurs participant à chaque conversation.
- **messages** : contient les messages envoyés dans les conversations.

### Relations

- Un utilisateur peut participer à plusieurs conversations.
- Une conversation peut avoir plusieurs utilisateurs.
- Un utilisateur peut envoyer plusieurs messages.
- Un message est envoyé par un seul utilisateur.
- Une conversation peut contenir plusieurs messages.
- Un message appartient à une seule conversation.

La relation entre les utilisateurs et les conversations est une relation **N:N**. Elle est donc représentée par la table d'association `participations`.
